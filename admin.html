Project Admin

Edit projects locally, then push to GitHub Pages

Local admin server required

The live GitHub Pages site is read-only. To add or edit projects, run the local admin server from your repo: 

python scripts/local_admin_server.py

Then open http://127.0.0.1:8000/admin.html, save your changes, and git add / git commit / git push to publish.

Login

Optional Firebase login (only if you still use Firestore). Preferred workflow is the local admin server.

After saving, publish with: git add -A && git commit -m "Update projects" && git push
